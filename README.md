# Conspiracy Gaming — Website

Official static website for **Conspiracy Gaming**, a tabletop gaming and community venue in **Wolcott, Connecticut**. The site highlights events, campaigns, merch, and ways for players to gather.

## Local development

This is a dependency-free static site. Open `index.html` directly for a quick preview, or serve the repository with any static web server.

## Brand direction

The visual system follows the original Conspiracy Gaming identity: a near-black foundation, white typography, neon-green accents, and deep navy/royal-blue event artwork. Primary public information is based on the original site at https://www.conspiracygamingtts.com.

## Location

**95 Wolcott Road, Wolcott, CT 06716**

## Deployment

The repository includes `vercel.json` and can be deployed as a static Vercel project.
